# sc-provider-core

Provider traits, deterministic local-first routing, streaming event types, and shared OpenAI-compatible transport support for SC Node.

The `Provider` trait, `EventStream`, provider errors, and routing module are covered by the alpha consumer contract. OpenAI transport schemas and the SSE decoder remain explicitly experimental. See [the public API policy](https://github.com/SC-LABS-ai/sc-node/blob/main/docs/API_STABILITY.md).
